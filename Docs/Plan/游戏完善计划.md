# 《再来一次》六项完善方向

2026-10-08 经用户确认，以下六项作为固定完善方向；本轮仅执行第 1 项，其他项进入后续计划。

| 顺序 | 方向 | 交付与验收 |
|---|---|---|
| 1 | 可靠性与存档 | 物品使用稳定 ID；背包、装备、商店、生命、关卡与周目重启后可恢复；旧档保留；损坏数据可回退；新游戏不误删其他设置。以独立进程保存/继续和实际构建验收。 |
| 2 | 形态与多种通关方法 | 人形战斗、隐形潜入、兽人交流各有用途和代价；先完善一个支持多种解法的关卡。 |
| 3 | 移动、战斗与交互反馈 | 明确点击目标、攻击距离、命中与受击反馈；优化拥挤和提示稳定性。 |
| 4 | 新手引导与关卡节奏 | 用任务依次引入移动、开箱、装备和变身；每层突出一个机制并安排综合运用。 |
| 5 | 画面统一与信息可读性 | 统一室内外光照和 UI；保证遮挡、暗处、群战中角色与危险可辨认。 |
| 6 | “再来一次”的重玩主题 | 用路线、敌人或装备组合产生下一轮变化，明确重玩动机后再决定永久成长。 |

执行原则：先稳住存档和操作基础，再完善关卡解法、引导与画面，最后扩展重玩。保留现有玩法与资产备份，不以新增内容掩盖基础问题。
