## 恢复方法

在新目录检出备份，避免覆盖当前工作的改动：

```sh
git clone --branch codex/backup-before-scene-layout-20261023 https://github.com/xhy0303/GraduationProject.git OneMoreTime-backup
```

使用 Unity 6000.5.10f1 打开，等待依赖解析与资源导入，从 `Assets/Scenes/Begin.unity` 启动。历史测试结果见 `Docs/Review`，历史通过不等于本轮重新验收。
